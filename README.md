Share-Codex 
旨在让国内开发者更轻松使用 GPT 模型，致力于解决官方订阅账号的降智与封号问题。
通过共享官方订阅资源、管理模型调用额度和简化 API 接入流程，让大家把更多时间用在开发上。

## 项目特点

- **无需美区信用卡**：轻松订阅官方套餐，获得共享号池额度。
- **无需自行搭建纯净 IP 环境**：减少个人准备和维护环境的负担。
- **减少账号风控与封号顾虑**：由共享号池集中管理订阅资源，解决降智与风控问题，降低个人维护账号的复杂度。
- **快速接入，保留完整模型能力**：通过 API 密钥接入 Codex 及兼容 OpenAI 接口的开发工具。
- **等额等量，与官方订阅额度相同**：按官方订阅实际API用量，从共享号池等额分发到每一位用户。
- **同步官方重置，补充对应额度**：官方完成重置后，所有用户同步补充相应配额。

## 如何使用

登录账号 → 选择官方订阅套餐 → 注入共享号池 → 领取对等用量额度 → 开始调用官方共享号池 API


## 项目初衷

**让大家在国内也能无门槛地用上 GPT 模型。**

很多开发者想用 GPT 写代码、学习新技术、验证一个想法，却先要花时间处理支付方式、网络环境和账号维护。这些准备工作，往往比开始使用模型本身更复杂。

我们希望通过共享订阅资源和简化接入流程，减少这些障碍，让更多开发者能够从一个 API 密钥开始，把模型能力用到自己的项目里。
